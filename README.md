# إرث العوالم — Legacy of Worlds

مشروع مانغا معجبين غير رسمي (Fan Work) في عالم ناروتو/بوروتو. هذا المستودع هو مرجع الاستمرارية والكتابة والتصميم وتتبع الصفحات.

## نقطة البداية
تبدأ القصة بعد حرب النينجا الرابعة ومع بدايات عصر بوروتو، وتتحرك عبر جبهتين مترابطتين: جبهة البعد الآخر وجبهة الأرض.

## ملفات المشروع
- [ذاكرة المشروع](PROJECT_MEMORY.md) — القرارات الثابتة ونقطة التوقف وبروتوكول العمل.
- [دليل العالم](WORLD_BIBLE.md) — قواعد العالمين والعبور والقوى والفصائل.
- [ملخص الفصل الأول](CHAPTERS/CHAPTER_01_SUMMARY.md) — الأحداث المعتمدة للفصل الأول.
- [فهرس الشخصيات](CHARACTERS/CHARACTER_INDEX.md) — الشخصيات المثبتة والمرشحة.
- [دليل الأسلوب الفني](MANGA_ART/STYLE_GUIDE.md) — أسلوب الرسم واتساق التصاميم.
- [متتبع الصفحات](PAGE_TRACKER.md) — حالة تخطيط ورسم كل صفحة.
- [سجل التغييرات](CHANGELOG.md) — سجل التحديثات.

## قاعدة الاستمرارية
قبل استكمال العمل، راجع ذاكرة المشروع ودليل العالم وآخر فصل. ميّز بين الحقائق المعتمدة والاقتراحات والعناصر غير المحسومة. لا تعتبر أي صفحة أو تصميم منجزًا نهائيًا قبل المراجعة والتوثيق.

## تنبيه الحقوق
هذا مشروع معجبين غير رسمي، ويستخدم عالمًا وشخصيات مملوكة لأصحاب الحقوق الأصليين. لا يدّعي المشروع أنه إصدار رسمي أو أنه يملك تلك الشخصيات.
